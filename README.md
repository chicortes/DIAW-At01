# API REST de Clima - Belo Horizonte

Atividade de Spring Boot que consulta o clima de Belo Horizonte usando a API do Open-Meteo.

## Tecnologias

- Java 21
- Spring Boot
- Maven
- REST API
- RestTemplate

## Como rodar

1. Clone o repositório
2. Entre na pasta do projeto
3. Rode com: ./mvnw spring-boot:run

4. Acesse: http://localhost:8080/climaBH

## Endpoint

GET /climaBH - retorna os dados climáticos atuais e previsão dos próximos dias de BH.

Não precisa de API Key, o Open-Meteo é gratuito.
